💍 AI Wedding Photo Organizer

An AI-powered wedding photo organizer using multimodal LLMs for intelligent image classification and automated photo organization.

---

🚀 Features
- LLM-based image understanding
- Wedding image classification
- Automatic folder organization
- Streamlit UI
- Gemini/OpenAI Vision integration

---

🛠 Tech Stack
- Python
- Streamlit
- Gemini API
- Pillow
- dotenv
